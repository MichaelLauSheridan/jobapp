Google Sheet tracker

When you mark a job applied, JobApp fills the next empty row of “{{ cfg.get('sheet_name') }}”, then keeps its Status up to date (interview, offer, rejected). It never deletes rows, changes formatting or blanks a cell, and only edits the row whose “{{ cfg.get('key_column') }}” matches the job.

One-time setup (about 3 minutes)

  1. Open the tracker sheet in Google Sheets → Extensions → Apps Script.
  2. Delete what's in Code.gs, paste the script on the right (Copy script), and click 💾 Save.
  3. Deploy → New deployment → gear icon → Web app. Set Execute as: Me, Who has access: Anyone. Click Deploy and authorize with the Google account that owns or edits the sheet.
    Google shows an “unverified app” warning because it's your own script: Advanced → Go to (project) → Allow. “Anyone” only lets someone who knows the private link and the secret key inside the script write rows.
  4. Copy the Web app URL (starts with https://script.google.com/macros/s/…) and paste it here:
